# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in `@agentonboard/sdk` (such as signature bypass, audience/issuer confusion, key-cache isolation issues, or JWT claim handling bugs), please **do not** open a public GitHub issue.

Instead, report it privately via:
- Email: `security@agentonboard.xyz`
- Or GitHub Security Advisories on this repository

Please include reproduction steps, affected versions, and impact. We will acknowledge receipt and coordinate a fix before public disclosure.
